## How it is built
- `scripts/sync-data.mjs` copies the API into `data/api/` (committed: the data in git); CI runs it before each build. It only ever calls data.promptugal.news.
- `scripts/build.mjs` renders everything; no dependencies. One event card shape for both kinds: `read` (from `/api/v1/events/by-place/<place>.json`) and `found` (from `/api/v1/events/claims/by-place/<place>.json`). "Today" is the build day in Lisbon; events ending before it are dropped; events started before it are "On now".
- "The Algarve" page uses the API's `algarve` read file and gathers the towns' claims (the API has no `algarve` claims file).
- The gate fails on an em dash anywhere in `_site/`, including source titles: `clean()` prints a source's em dash as an en dash, said on `/how/`. A hype word in a source's title would also fail the gate; none so far. If one comes, raise it with Dinis rather than weaken the check.
